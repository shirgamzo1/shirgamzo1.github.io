shir-claude

A personal OAuth app that lets Claude Code work with the developer's own Gmail and Google Drive.

What it is

shir-claude is a private, single-user Google OAuth client. It authorizes locally running Claude Code tools (MCP servers) on the developer's own computer to access the developer's own Google account. It is not a public service, it is not offered to other users, and it has no servers of its own.

What it does

  • Gmail: search and read messages, create draft replies, send email when explicitly asked, and manage labels and basic mail settings.
  • Google Drive: find, read, create and update files when explicitly asked.

All actions happen only in response to the developer's own requests in Claude Code.

Your data
OAuth tokens are stored only on the developer's computer. Google data is never sold, never used for advertising, and never shared except as described in the Privacy Policy.

Contact

Questions about this app can be sent through GitHub Issues or the developer's GitHub profile.
