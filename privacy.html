Privacy Policy

Effective date: October 6, 2026

This Privacy Policy explains how shir-claude ("the app") accesses, uses, stores and shares Google user data. The app is a personal, single-user OAuth client that connects Claude Code, running on the developer's own computer, to the developer's own Google account. It is not offered to the public and has no servers of its own.

1. Data the app accesses

With the account owner's consent on Google's consent screen, the app may access:

  • Gmail: email messages, threads, attachments, drafts, labels and basic mail settings (scopes such as gmail.modify and gmail.settings.basic).
  • Google Drive: files and folders, including their content and metadata, as permitted by the Drive scopes granted on the consent screen.
  • Basic account information: the email address of the connected account, when needed to identify it.

2. How the data is used

Google user data is used only to perform actions the account owner explicitly requests in Claude Code, for example:

  • searching, reading and summarizing email;
  • drafting replies, and sending email only when explicitly instructed;
  • applying labels and managing basic mail settings;
  • finding, reading, creating and updating Drive files.

The data is not used for advertising, is not sold, and is not used to build user profiles. The app does not use Google user data to develop, improve or train generalized artificial intelligence or machine learning models.

3. How the data is stored

  • OAuth access and refresh tokens are stored only on the developer's computer, in files in the user's home directory.
  • The app does not copy Gmail or Drive content to any database or server of its own. It has none.
  • Claude Code may keep local session history on the same computer, which can include content retrieved during a session.

4. How the data is shared

When the account owner asks Claude Code to work with email or files, the relevant content is sent over an encrypted connection to Anthropic, the provider of the Claude AI model, so it can generate the requested response. Anthropic processes this data under its own Privacy Policy and the account's data settings.

Google user data is not shared with or transferred to anyone else, except where required by law.

5. Google API Services User Data Policy

shir-claude's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

All communication with Google APIs uses HTTPS. Tokens are kept on a computer protected by the owner's operating-system account and are never published or committed to source control.

7. Retention and deletion

  • Tokens are kept until access is revoked or the token files are deleted.
  • Access can be revoked at any time at myaccount.google.com/permissions. After revocation the app can no longer access the account.
  • Deleting the local token files removes the app's stored credentials from the computer.

8. Children

The app is a personal tool and is not directed to children under 13.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.

10. Contact

Questions about this policy can be sent through GitHub Issues or the developer's GitHub profile.
